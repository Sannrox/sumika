# Week 0 decisions

- Status: accepted
- Date: 2026-09-20

The habitat is named **sumika**. The CLI is `sumika`; the supervisor is `sumika daemon`. There is no `agentsd`.

Language is Rust (edition 2024, toolchain 1.97.1). PTY is `portable-pty`. Control IPC is Unix socket JSON-lines; attach JSON-handshakes on a second connection then becomes raw PTY bytes. Picker UI is `ratatui` + `crossterm` (phase 1). Attach exclusivity is steal. Scrollback is none until a last-frame snapshot. Config is `~/.config/sumika/config.toml`. Socket is `$XDG_RUNTIME_DIR/sumika/sumika.sock` when that runtime dir is set, else a user-owned 0700 directory (`~/Library/Caches/sumika` on macOS, `~/.cache/sumika` elsewhere). Not a shared `/tmp` path. Accept only same-uid peers. Daily-driver service is a macOS launchd user agent; a systemd `--user` unit ships but is not the week-3 path. Notify is macOS Notification Center first. Auto-respawn never: dead stays dead until `r` / `start`. One installed binary.

These choices are locked. Do not reopen them to look more like a multiplexer.
